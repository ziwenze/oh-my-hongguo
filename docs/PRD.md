## 1. 产品定位与目标用户 (Product Definition)

### 1.1 产品愿景
Oh-My-Hongguo 是一款为 Windows 与 macOS 用户打造的现代短剧客户端。桌面端用户长期面临“用安卓模拟器卡顿占内存”、“网页端黑边巨大且无法快捷切集”的痛点。本项目旨在提供：
- 原生桌面级别的交互流畅度（毫秒级响应、键盘全功能控制）；
- 专为 9:16 短剧优化的视窗体验（自由缩放自适应、独立置顶摸鱼小窗）；
- 完整的内容发现、排行榜、搜索与个人本地追剧数据中心。

### 1.2 目标用户画像
1. **多任务/摸鱼型用户**：在办公、编码、写文档时，希望在屏幕角落放置一个轻量、不抢焦点的短剧小窗，自动连播；
2. **沉浸式刷剧用户**：大屏环境下喜欢类似抖音般通过滚轮或键盘上下滑快速找剧、连续追剧的用户；
3. **技术探索者**：对开放协议、本地媒体解封装及桌面客户端工程感兴趣的技术人员。

## 2. 功能模块详细设计 (Functional Specifications)

### 2.1 模块一：发现流与频道系统 (Discovery & Channel)
- **频道导航栏**：
  - 支持顶级频道切换：`精选推荐`、`短剧榜单`、`新剧抢先`、`女生偏好`、`男生偏好`、`动态漫剧`；
  - 频道支持横向滚动与快捷切换；
  - 数据来源于 SDK `discover()` 与 `categories()`。
- **瀑布流短剧卡片 (Drama Card 规范)**：
  - **海报封面**：圆角 8px，宽高比 3:4，支持懒加载（IntersectionObserver）与暗色渐变骨架屏；
  - **角标体系**：
    - 状态角标（右下角）：已完结显示 `全 N 集`（绿色/高亮），更新中显示 `更新至 N 集`（蓝色）；
    - 题材角标（左上角）：如 `战神`、`甜宠`、`穿越`、`逆袭`；
  - **元数据信息**：
    - 主标题（最多 2 行，超出省略号）；
    - 红果热度值：显示 `🔥 热度 N 万`；
    - 播放量 / 追剧人数（服务端给出时显示）；
  - **交互操作**：
    - 悬停（Hover）呈现微放大动效，浮现浮层按钮：`立即播放`、`追剧收藏`；
    - 点击卡片直接进入详情弹窗或剧场播放页。
- **分页与无限加载**：
  - 滚动到底部触发下一页加载，带加载动画（Spinner）；
  - 利用 SDK 游标机制自动过滤跨页重复短剧，触底无更多时呈现“已加载全部内容”。

### 2.2 模块二：智能搜索与排行榜 (Search & Ranking)
- **智能搜索栏**：
  - **未激活状态**：输入框内轮播提示词（来源于 SDK `searchCues()`，每 4 秒淡入淡出轮换）；
  - **聚焦状态**：展开搜索下拉面板，展示：
    - 搜索历史记录（本地存储，支持单条删除和一键清空）；
    - “猜你想搜”标签组与“热搜总榜”Top 10（来源于 SDK `hotSearch()`）；
  - **输入状态**：防抖 300ms 触发联想词获取（SDK `suggest(query)`），高亮匹配关键字，支持键盘上下键直接选词回车搜索。
- **多维度排行榜单页 (Ranking View)**：
  - 榜单类别切换：`短剧热播榜`、`新剧飙升榜`、`人气榜`、`演员榜`（SDK `shortRank()` 与 `ranking()`）；
  - 榜单条目展示 Top 1~Top 3 专属金银铜徽章、剧照、上升热度趋势；
  - 演员榜展示演员头像、参演代表作及“进入演员作品页”入口。
- **分类筛选面板 (Filter Panel)**：
  - 题材类型：`全部` / `真人短剧` / `动态漫` / `AI剧` / `影视剧`；
  - 状态筛选：`全部` / `更新中` / `已完结`；
  - 范围过滤：`全部` / `未看过`；
  - 筛选条件组合即时响应，重新拉取筛选结果（SDK `shortFilter()`）。

### 2.3 模块三：播放器与视窗形态 (Player & View Modes)
- **三种视窗形态**：
  1. **竖屏沉浸模式（主打）**：
     - 针对 9:16 画幅优化，默认提供 450×800 舒适预设，**窗口完全允许用户自由缩放拖拉**；
     - 视频显示区域使用 `object-fit: contain` 居中贴合，杜绝画面变形拉伸；两侧留白呈现环境毛玻璃暗色微光；
  2. **宽屏剧场模式**：
     - 适应桌面宽屏显示器，采用“左侧核心播放器 + 右侧可折叠选集抽屉/剧情简介”；
  3. **独立置顶摸鱼小窗 (Always-on-Top Floating Player)**：
     - 由 Electron 独立 BrowserWindow 渲染，窗口默认置顶（`alwaysOnTop: true`）；
     - 默认尺寸 280×498，支持通过滑块微调窗口透明度（0.4 ~ 1.0）；
     - 共享单一播放会话状态机（详见架构设计），无缝接力续播。
- **短剧刷剧交互 (Feed Mode)**：
  - 沉浸模式下，鼠标滚轮触发**防抖切集**（防抖时间 350ms，且带触控板微小惯性位移过滤）；
  - 键盘快捷键提供双层维度操作（详见快捷键表）。
- **动态清晰度与音轨**：
  - 根据服务端实际返回的 `streams` 列表动态生成清晰度选项菜单（如 1080p / 720p / 540p / 480p / 360p），不写死选项；
  - 支持自动记忆用户选择的清晰度；
  - DASH 作品若带有独立音轨（`audio_url`），由播放器同步拉取并双轨混音。
- **连播与预加载探索**：
  - 当前集剩余时长 ≤ 15 秒时，后台异步获取下一集播放元数据，目标降低切集首帧等待。

### 2.4 模块四：选集与多季联动系统 (Episode System)
- **分集网格与分页取回机制**：
  - 明确区分**总集数结构展示**与**实际拉取到的分集数据**：依据服务端给出的 `episode_count` 生成分段分页器（如 `1-30`、`31-60`、`61-90`），仅在用户切换到对应区间时，通过 SDK `listEpisodes(seriesId, { offset, limit })` 实际拉取该页真实的 `Episode` 列表，严禁在未拉取时凭空构造虚假的分集 ID；
  - 分集卡片标注真实序号、更新标志（`is_new`）、禁用标记（`playable: false`）；
  - 高亮“正在播放”、“已播放完”、“断点续播”状态。
- **多季合集切换**：
  - 作品若为多季（`is_multi_season: true`），在选集顶部展示“第一季”、“第二季”选项卡，点击无缝切换（SDK `seasons()` / `getAlbum()`）。
- **演员专辑与原著小说**：
  - 详情页展示主演演员列表，点击进入演员主页及作品集（SDK `person()`、`personWorks()`）；
  - 若关联原著小说，展示小说原著卡片及简要信息。

### 2.5 模块五：个人数据中心与存储 (Library & History)
- **秒级断点续播 (Watch History)**：
  - 记录字段：`seriesId`, `episodeId`, `episodeNumber`, `title`, `positionSeconds` (秒级浮点), `durationSeconds`, `updatedAt`；
  - 进度保存策略：播放过程中每 5 秒自动节流写入内存，切集、暂停或关闭窗口时立刻同步刷入存储；
  - 首页常驻“继续观看”卡片，点击一键恢复播放。
- **追剧收藏夹 (Favorites)**：
  - 本地单键收藏/取消收藏，按更新时间/收藏时间排序；
  - 收藏短剧有更新时（`is_new` 或更新至新集数），卡片红点高亮提示。

### 2.6 模块六：故障与错误交互状态规范 (Error & Diagnostics)
明确定义客户端各层异常的 UI 交互与反馈机制，杜绝黑屏死锁：

| 错误类型 | 触发场景 | 客户端表现与交互 | 恢复与处理行为 |
| :--- | :--- | :--- | :--- |
| **AUTH_LIMIT** | 接口返回 `ANONYMOUS_LIMITED` | 播放器遮罩提示：“平台访问频控受限，请稍后再试” | **不进行后台自动无感换号重试**；停止请求并向用户如实展示平台状态，提供手动“诊断并重试”按钮。 |
| **CONTENT_UNAVAIL** | 内容下架或版权受限 | 提示：“该剧集在当前网络区域不可用或已下架” | 停止缓冲，提供“返回上一页”或“下一集”按钮。 |
| **DRM_UNSUPPORTED** | 媒体为 CENC 加密但无可用解密能力 | 提示：“当前播放环境缺少该受保护媒体的解码组件” | 弹出诊断信息与环境检查指引，记录日志。 |
| **NET_OFFLINE** | 网络断开连接 | 顶部出现橙色横条提示：“网络已断开，请检查网络设置” | 监听系统网络恢复事件（`online`），自动重连。 |
